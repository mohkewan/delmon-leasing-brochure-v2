# نظام بروشور التأجير — شركة دلمون للاستثمار

منصة ويب متكاملة لإنشاء بروشورات تأجير احترافية لمشاريع دلمون العقارية، مع تصدير PDF بجودة عالية وأرشفة البروشورات.

**الرابط المنشور:** https://delmonbroch-j5bkujfh.manus.space/

---

## التشغيل المحلي

### المتطلبات
- Node.js 22+
- pnpm
- Chromium (لتوليد PDF)
- قاعدة بيانات MySQL/TiDB (تُوفَّر تلقائياً في بيئة Manus)

### خطوات التشغيل
```bash
# تثبيت Chromium (Ubuntu/Debian)
sudo apt-get install -y chromium

# تثبيت الاعتماديات
pnpm install

# تطبيق مخطط قاعدة البيانات
pnpm db:push

# تشغيل بيئة التطوير
pnpm dev
```

الخادم يعمل على `http://localhost:3000`

## الميزات الفعلية الحالية (مُتحقَّق منها)

### إدخال البيانات
- **تبويب بيانات المشروع**: اسم المشروع، النوع، المدينة، الموقع، المساحة، عدد الطوابق، سنة الإنجاز، الوصف، المرافق، صورة المشروع
- **تبويب الوحدات**: إضافة وحدات شاغرة مع رقم الوحدة، النوع، المساحة، الإيجار الشهري، الدور، الحالة
- **تبويب معلومات التواصل**: اسم المسؤول، الهاتف، البريد الإلكتروني، العنوان
- **اختيار من قائمة مشاريع دلمون**: تحميل بيانات مشروع موجود مسبقاً
- **حفظ تلقائي في المتصفح** (localStorage): البيانات تبقى بعد إغلاق المتصفح

### تصدير البروشور
- **3 قوالب**: Classic (أبيض/ذهبي)، Dark Luxury (داكن/ذهبي)، Bold Magazine (مجلة)
- **10 صفحات لكل قالب**: غلاف، تفاصيل المشروع، جدول الوحدات، صور المشاريع، رؤية المشروع، مؤشرات مالية، جدول تفصيلي، شروط التأجير، غلاف خلفي
- **تصدير PDF**: جودة عالية عبر Puppeteer + Chromium على السيرفر
  - **ملاحظة production**: يتطلب Chromium في صورة Docker — تم إضافة `Dockerfile` بتثبيت `chromium` تلقائياً
- **تصدير Excel**: جدول الوحدات بتنسيق xlsx
- **تصدير JSON**: نسخة احتياطية من بيانات المشروع
- **مشاركة واتساب**: رابط مباشر مع ملخص المشروع
- **تنسيق الأرقام en-US**: جميع الأرقام تظهر بالأرقام الغربية (37,000 م²، 157,500 ر.س)

### جودة البيانات (مُتحقَّق منها)
- **مؤشر اكتمال البيانات**: يحسب نسبة اكتمال الحقول المالية في الوقت الفعلي
- **badge تحذير "بيانات ناقصة"**: يظهر بجانب الوحدات الناقصة
- **تحذير قبل التصدير**: dialog واضح إذا كانت هناك وحدات بلا إيجار أو مساحة، مع خيار "إلغاء وتصحيح" أو "متابعة على أي حال"
- **تصحيح إملائي تلقائي**: يُصحّح الأخطاء الشائعة عند التصدير
- **تحسين الصور**: معالجة تلقائية بـ sharp عند رفع صورة المشروع

### الأرشيف (يتطلب تسجيل الدخول)
- حفظ البروشورات المكتملة في قاعدة البيانات
- عرض الأرشيف على `/archive` مع تاريخ الإنشاء وإمكانية إعادة التحميل

### توليد AI (يتطلب تسجيل الدخول)
- توليد صفحات البروشور بالذكاء الاصطناعي عبر `/ai-generator`
- قد يستغرق 3-5 دقائق

## هيكل الملفات الرئيسية

```
client/src/
  pages/
    Home.tsx              ← الصفحة الرئيسية (إدخال البيانات + معاينة)
    Archive.tsx           ← صفحة الأرشيف
    AiBrochureGenerator.tsx ← واجهة توليد AI
  components/
    ProjectTab.tsx        ← تبويب بيانات المشروع
    UnitsTab.tsx          ← تبويب الوحدات
    ContactTab.tsx        ← تبويب التواصل
    BrochurePreview.tsx   ← معاينة القالب Classic
    BrochurePreviewDark.tsx ← معاينة القالب Dark
    BrochurePreviewMagazine.tsx ← معاينة القالب Magazine

server/
  pdfRoute.ts            ← محرك PDF (10 صفحات × 3 قوالب) — Puppeteer + Chromium
  imageEnhanceRoute.ts   ← تحسين الصور بـ sharp
  aiGenerationRoute.ts   ← توليد البروشور بالذكاء الاصطناعي
  routers.ts             ← tRPC procedures (auth, brochures, analytics)

drizzle/schema.ts        ← مخطط قاعدة البيانات (users, brochures, brochure_jobs, analytics)
Dockerfile               ← صورة Docker مخصصة تتضمن Chromium + fonts-noto-cjk
docs/archive/            ← ملفات الهوية البصرية والمراجعات الداخلية
```

## متغيرات البيئة

جميع المتغيرات تُحقن تلقائياً في بيئة Manus. للتشغيل المحلي يلزم:
- `DATABASE_URL` — رابط قاعدة البيانات MySQL
- `JWT_SECRET` — مفتاح توقيع الجلسة
- `BUILT_IN_FORGE_API_KEY` / `BUILT_IN_FORGE_API_URL` — للذكاء الاصطناعي وتحسين الصور
