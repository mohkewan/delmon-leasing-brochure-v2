# مواصفات قالب بروشور الوحدة التسويقي — دلمون للاستثمار

## الهدف

تمكين مسؤول التأجير من إدخال بيانات المشروع والوحدة مرة واحدة، ثم الحصول على بروشور تسويقي جاهز للإرسال يعرض الوحدة كفرصة واضحة ومهنية، وليس كقائمة بيانات داخلية.

## المسار التسويقي للعميل

| الصفحة | الرسالة التسويقية | البيانات المصدرية |
|---|---|---|
| الغلاف | فرصة تأجير واضحة في مشروع محدد | اسم المشروع، المدينة، نوع المشروع، الصورة، عدد الوحدات المتاحة. |
| الملخص | لماذا تستحق الوحدة المعاينة؟ | اسم/نوع الوحدة، المساحة، الطابق، الموقع، وصف قصير. |
| المواصفات | بيانات قرار قابلة للمقارنة | رقم الوحدة، المساحة، الطابق، النوع، الإيجار أو السعر عند إدخاله. |
| المزايا | عناصر القيمة الملموسة | مزايا الوحدة ومرافق المشروع المدخلة فقط. |
| الموقع والمشروع | تعزيز الثقة بالمشروع | وصف المشروع، المدينة، الحي، صور المشروع الفعلية. |
| البدائل | زيادة فرصة الإغلاق | بقية الوحدات المكتملة في المشروع، عند وجودها. |
| التواصل | دعوة فورية للإجراء | اسم مسؤول التأجير، الهاتف، البريد، وعبارة «احجز معاينتك». |

## قواعد الهوية والتصميم

| القاعدة | التطبيق |
|---|---|
| الإيقاع البصري | خلفية بيضاء، ترويسة رفيعة، إطارات زرقاء فاتحة، ومساحات تنفس واسعة. |
| الألوان | زيتوني `#949437` للمحاور الرئيسية، أزرق فاتح `#94B6D2` للإطارات والمساند، فحمي `#262626` للنصوص، وبرتقالي `#DD8047` لتنبيه محدود. |
| الخط | Cocon® Next Arabic عند توفر ترخيص الويب؛ Cairo كبديل إنتاجي متوافق. |
| الصورة | صور المشروع والوحدة الحقيقية فقط، مع طبقة لون خفيفة أو معالجة أحادية هادئة عند الحاجة. |
| النص | عنوان قوي، وصف من سطرين كحد أقصى، وحقائق مسندة للبيانات المدخلة فقط. |
| الأيقونات | أيقونات خطية موحّدة، بلا رموز تعبيرية. |

## تحسينات واجهة المسوق

1. تستبدل خيارات النمط المتنافسة بتجربة «هوية دلمون المعتمدة» الواضحة.
2. تتحول بطاقة الوحدة إلى بطاقة فرصة توضح مدى اكتمالها وجاهزيتها للتسويق.
3. تعرض المعاينة المصغرة إطاراً مطابقاً للبروشور، وحالة «جاهز للمشاركة» عند اكتمال الحقول الأساسية.
4. يجعل زر التصدير دعوة مباشرة: «تصدير بروشور تسويقي PDF».
5. توجّه حقول الوصف والمزايا المستخدم إلى معلومات تسويقية قصيرة قابلة للنشر، من دون إدخال ادعاءات عامة.
